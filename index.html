SCRAPY

Listado con comandos básicos para utilizar SCRAPY:

1. Documentación oficial y guías de instalación haciendo click aquí.

2. Abrir una terminal con tu entorno virtual activo.

Configuración Inicial (Globales)
  • scrapy startproject nombre_proyecto para crear la estructura base de directorios y archivos de configuración para un nuevo proyecto.
  • scrapy genspider nombre_araña dominio.com para generar una nueva araña utilizando plantillas predefinidas dentro del proyecto actual.
Desarrollo y Pruebas (Interactivos)
  • scrapy shell "URL" para abrir una consola interactiva y probar selectores CSS o XPath en tiempo real sobre la página indicada.
  • scrapy fetch "URL" para descargar el código HTML de una página web utilizando el descargador de Scrapy y visualizarlo en la terminal.
  • scrapy view "URL" para descargar y abrir la página web en tu navegador tal y como la ve Scrapy (ideal para verificar contenidos cargados por JavaScript).
Ejecución y Extracción
  • scrapy crawl nombre_araña para ejecutar una araña específica definida en nuestro proyecto e iniciar la recolección de datos.
  • scrapy crawl nombre_araña -O archivo.json ejecuta la extracción y exporta directamente los resultados a un archivo estructurado (admite .json, .csv, .xml). La opción -O mayúscula sobreescribe el archivo.
  • scrapy list para mostrar una lista con los nombres de todas las arañas disponibles en el proyecto actual.
